# Chữ ký số trên module Sign của Odoo

Dự án tích hợp chữ ký số công cộng của các CA Việt Nam (VNPT SmartCA, Viettel MySign, USB token…) vào Odoo Sign, để hợp đồng ký trên Odoo có giá trị pháp lý đầy đủ theo Luật Giao dịch điện tử 2023 và Nghị định 23/2025/NĐ-CP.

- Đề xuất phương án (chờ phê duyệt): [docs/de-xuat-chu-ky-so-odoo-sign.md](docs/de-xuat-chu-ky-so-odoo-sign.md)
