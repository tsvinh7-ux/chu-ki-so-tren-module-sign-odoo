# Chữ ký số trên module Sign của Odoo

Addon tích hợp chữ ký số công cộng của các CA Việt Nam (CKS cloud, USB token) vào Odoo Sign, không sửa Odoo Sign, để hợp đồng ký trên Odoo có giá trị pháp lý đầy đủ theo Luật Giao dịch điện tử 2023 và Nghị định 23/2025/NĐ-CP.

- **Phương án chốt v2 (chờ phê duyệt):** [docs/phuong-an-chot-v2.md](docs/phuong-an-chot-v2.md)
- Đề xuất v1, gồm căn cứ pháp lý: [docs/de-xuat-chu-ky-so-odoo-sign.md](docs/de-xuat-chu-ky-so-odoo-sign.md)
